# Sistemas Embarcados e IoT - Maquete Automação Residencial (Mundo SENAI 2026)

## Sobre a Apresentação
* **O que foi apresentado:** Maquete de automação residencial interativa (casa, sobrado e garagem) controlada por um microcontrolador ESP32. O sistema executa controle de iluminação, ventilação automática por temperatura, varal inteligente com sensor de chuva, alarme de incêndio com detecção de fumaça e garagem automatizada via sensor ultrassônico, com controle por interface web e por comandos de voz via assistente Alexa.
* **Público-alvo:** Visitantes da comunidade, estudantes de outras turmas e docentes do SENAI.
* **Meu papel:** Apresentação prática dos comandos e do funcionamento da maquete para os visitantes durante o evento.

## Principais Aprendizados
* Como explicar conceitos complexos de Internet das Coisas (IoT), pinos lógicos de 3,3V/5V e relés sem utilizar siglas difíceis para o público leigo.
* Demonstração ao vivo da resposta dos atuadores (lâmpadas, servo motor e sirene) acionados via interface web e integração de voz em tempo real.
